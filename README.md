# Mini String Utility Program

## Description

This is a simple Python console application that performs basic string-related operations using a menu-driven interface. It is designed for beginners to practice Python string concepts and conditional statements.

## Features

- Name Formatter
- Email Validator
- Word Counter
- Palindrome Checker

## Technologies Used

- Python 3
- Visual Studio Code

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/mini-string-utility.git
```

2. Navigate to the project folder:

```bash
cd mini-string-utility
```

3. Run the program:

```bash
python mini_string_utility.py
```

## Sample Menu

```text
1. Name Formatter
2. Email Validator
3. Word Counter
4. Palindrome Checker
```

## Python Concepts Used

- Variables
- User Input
- Strings
- String Methods
- Conditional Statements (`if`, `elif`, `else`)
- String Slicing
- Built-in Functions (`input()`, `print()`, `len()`)
